AIチャット（案件ごとのAI相棒）

過去実績コンテキスト参照

🆕 本日

チャットを開くたびに自社の過去実績データ（品名・単価・使用回数）を自動で読み込む。
「システムバスはいくら？」→「過去実績では¥551,700です（8回使用）」のように根拠付きで回答。データが増えるほど賢くなる。

自動入力された単価には 「実績」 バッジを表示し、手動で上書きも可能。

案件完了 → マスター自動還元

🆕 本日

案件ステータスを「完了」にした瞬間、その案件で使った品名・単価・単位が自社マスターデータに自動で書き込まれる。
同じ品目を使うたびに使用回数も蓄積。データが育つほどAIの回答精度が上がる。

自社マスターデータ（蓄積型）

✓ 完成
  • 過去に使った品名・単価・使用回数を蓄積
  • 使用頻度の高い品目が上位に来る
  • AIチャットの単価回答・自動補完の精度に直結
  • Excelからのマスターデータ取り込みも対応
商談で伝えるポイント
🤖
AIは「整理係」、判断するのは社長 金額の確定・発注・通知はAIが自動では行わない。候補や下書きを出すだけで、最終判断は常に担当者。だから安心して使える。
📈
使えば使うほど賢くなる 案件を完了にするたびに単価データが蓄積。AIチャットへの「この品目いくら？」という質問への回答精度が、案件を重ねるごとに上がっていく。
💬
社長の相棒として話しかけられる 「システムバスの相場は？」「水回りで抜けてる項目は？」を自然な日本語で聞ける。自社の過去実績をもとに根拠付きで答える。
📄
見積から挨拶状まで書類が揃う 見積エディタ → 見積書 → 請求書 → 挨拶回り文書まで、案件に紐づいた書類を一か所で管理・出力できる。
🔒
原価・粗利は外に出さない設計 AIチャットの回答・顧客向け書類には原価・業者名が含まれない。セキュリティの考え方を最初から設計に組み込んでいる。
